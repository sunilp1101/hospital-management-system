# Hospital Management System

The Hospital Management System is a web-based application developed using Python and Django to manage hospital operations efficiently. It helps staff manage patients, doctors, appointments, medicines, and billing.

## Features
- Patient Registration and Management
- Doctor Management
- Appointment Booking and Tracking
- Medicine and Pharmacy Management
- Billing and Payment Status Management
- Invoice Generation and Printing
- Admin Panel for Managing Hospital Data
- Online Appointment Booking

## Technologies Used
-  Python
-  Django
-  HTML
-  CSS
-  Bootstrap
-  MySQL
